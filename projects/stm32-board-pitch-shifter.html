STM32 board Pitch shifter

status: Ongoing

Using Board STM32L4S5's MIC function, we aim to record a max 60s audio file from the sounds collected by the STM32 board.

Options in python manager file controls the timing of recording, file saving location, and how much the audio pitch shift.
Current option compose of a range of -12~+12(essentially 2 octaves in total).

Main Code for recording and pitch modulation is organized in main.c written by STM32CUBEIDE.

The project is ongoing, currently resolving issues with low writing speed.
